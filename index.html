Design review · Android

Your app's design, judged without mercy.

Pick an Android Studio project. Every screen is drawn exactly as its XML describes it, then checked against the rules real design reviews use. “It works” is not a pass.

  • Contrast every text measured against WCAG 2.2 AA
  • Touch targets anything tappable under 48×48dp
  • Type text under 12sp, sizes in dp, a missing type scale
  • Tokens hard-coded colours and off-grid spacing
  • States no empty, loading or error state where the code needs one
  • Labels & copy unlabelled icons, hard-coded strings, vague buttons
